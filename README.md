# 💼 Featured Projects

## 🏢 Solutec PNR

> **Full-stack business operations and management platform**

Solutec PNR is a production-focused business platform designed to manage operational workflows across **customers, resellers, support teams, administrators, products, inventory, and orders**.

### Core Features

- Product management
- Inventory management
- Serialized stock tracking
- Customer management
- Reseller management
- Order processing
- Multi-role administration
- Role-based access control
- Real-time customer support
- Support ticket assignment
- Support escalation workflows
- SMS notifications
- Customer restriction workflows
- Appeal handling
- Company settings
- Centralized branding
- Audit and operational workflows
- Database migration management
- Production deployment automation

### Real-Time Support Architecture

The support system handles conversations across multiple support levels:

```text
Customer / Reseller
        ↓
Support Staff
        ↓
Sub-Admin
        ↓
Super Admin
```

The system can use:

- Staff availability
- Online / Away / Offline presence
- Heartbeat tracking
- Ticket workload
- SLA deadlines
- Automatic escalation
- SMS alerts
- Secure conversation links

### Serialized Inventory

The system supports products where every physical unit can have its own serial number.

Example:

```text
Product: Network Camera
Stock: 3

Serial Numbers:
SN-001
SN-002
SN-003
```

Stock can be synchronized with valid serial quantities for serialized products.

### Production & Deployment

The application uses containerized services and automated deployment workflows.

Production architecture includes:

- FastAPI backend

- Flutter admin frontend
- Flutter support frontend
- PostgreSQL
- Background workers
- Nginx
- Docker Compose

- Health checks

## 🎓 WhatsApp Education Bot

> **AI-powered tutoring and learning platform delivered through WhatsApp**

The WhatsApp Education Bot is a conversational learning platform designed to help students study through structured teaching sessions directly inside WhatsApp.

The system combines **WhatsApp messaging, backend teaching logic, student conversation context, curriculum-aware responses, and AI-generated tutoring**.

### Core Features

- AI-generated tutoring responses
- Student conversation history
- Curriculum-aware teaching
- Past-question support
- Student context and memory
- Guided teaching workflows
- WhatsApp webhook integration
- Message processing
- Response validation
- Error handling
- Backend persistence
- Student state management
- Source verification
- Safe student-facing responses

### Message Architecture

```text
Student
   ↓
WhatsApp
   ↓
Webhook
   ↓
Backend
   ↓
Teaching Logic
   ↓
AI Provider
   ↓
Curriculum / Database
   ↓
Generated Teaching Response
   ↓
WhatsApp
```

### Reliability & Processing

The backend includes structured message processing states such as:

```text
RECEIVED
PROCESSING
COMPLETED
FAILED
```

This helps prevent duplicate processing and improves reliability when handling WhatsApp webhook events.

### Teaching System

The tutoring logic is designed to:

- Explain concepts
- Ask follow-up questions
- Evaluate student answers
- Maintain conversational context
- Guide students through lessons
- Handle misunderstandings safely
- Continue learning sessions naturally

### Tech Stack

`WhatsApp Cloud API`

`AI APIs`

`Webhooks`

`Database`

`Conversation Memory`

`Backend Services`
